# Travel Pin · 点亮足迹

记录并点亮你的旅行足迹：2D/3D 地图展示、旅程连线、多段日期、标签统计，纯前端构建
（MapLibre GL + globe.gl），无构建步骤，本地打开即可运行。

## 运行

```bash
./start-travel-pin.sh          # 或: python3 serve.py 8899
```

浏览器打开 <http://127.0.0.1:8899/>。数据读写走 `data/travel.json`，另有
`POST /api/save` 接口(见 `serve.py`)；编辑能力默认可用(本地开发视为可信环境)。

## 使用指南

**访客(公开站点)只读**：能看到地图与数据，但所有编辑、导入、导出、保存按钮均不显示。
**属主**点击顶栏**锁图标**，输入部署时设置的 `EDIT_PASSWORD`，即进入编辑模式
(token 24 小时有效，过期重新输入)。

### 顶栏按钮

| 按钮 | 图标 | 功能说明 |
|---|---|---|
| 2D / 3D | `2D / 3D` | 切换平面地图 / 地球仪视图 |
| 侧栏 | ![侧栏](docs/icons/panel.svg) | 收起/展开左侧列表与统计 |
| 关联数据文件 | ![关联数据文件](docs/icons/file-link.svg) | **(仅编辑模式)** 在 Chrome/Edge 中绑定一个本地 JSON 文件，之后每次增删改都**自动写回**该文件，作为本地自动备份；Firefox/Safari 不支持，提示改用「导出」 |
| 保存 | ![保存](docs/icons/save.svg) | **(仅编辑模式)** 本地开发：写回 `data/travel.json`；部署站点：把当前数据写入 Cloudflare KV 并立即发布 |
| 导出 JSON | ![导出 JSON](docs/icons/download.svg) | **(仅编辑模式)** 手动下载一份当前数据快照(JSON 文件)，可随时存档/迁徙 |
| 导入 JSON | ![导入 JSON](docs/icons/upload.svg) | **(仅编辑模式)** 从 JSON 文件导入，覆盖当前数据(导入前建议先导出备份) |
| 恢复默认数据 | `恢复默认数据` | **(仅编辑模式)** 清空当前数据并恢复为内置虚构示例 |
| 锁图标 | ![锁图标](docs/icons/lock.svg) | 进入/退出编辑模式；登录失败有次数限制 |
| 主题 | ![主题](docs/icons/moon.svg) | 明暗主题切换 |

### 数据存储位置(部署站点)

| 存储 | 位置 | 说明 |
|---|---|---|
| 线上权威数据 | Cloudflare KV | 每次保存的整体写入点，站点读取来源；**重新部署不会清除它** |
| 本地自动备份 | 你选的文件 | 通过「关联数据文件」授权后自动写回 |
| 浏览器缓存 | localStorage | 读取时留下的本地副本，仅当前浏览器可见，非权威 |

建议定期用「导出 JSON」或在 Chrome/Edge 中「关联数据文件」做本地备份——
KV 是线上唯一副本，误操作覆盖后无法回滚(本方案不保留历史版本)。

## 部署

**本仓库仅作代码开源分享**：不含部署配置、真实项目名或站点地址；部署与 GitHub 完全解耦，
完全在本地完成(通用教程见 [DEPLOY.md](DEPLOY.md)，除它以外的仓库文件不含任何部署信息)。

- 静态站点与接口托管在 Cloudflare Pages(Functions 提供 `/api/data`、`/api/authorize`、`/api/save`)
- 真实数据存放在 Cloudflare KV，仓库中只有脱敏示例数据
- 发布用**本地自用脚本**(`deploy.sh`，只在你本地、不入库)：发布「已提交进 git」的文件快照，
  未跟踪的真实数据永远不会上传
- 访客只读；属主输入密码换取 24h token 后可在页面直接编辑，改动实时发布

## 数据与隐私

本公开仓库中的 `data/travel.json` 与内联种子数据均为**虚构示例**，不含任何真实足迹。
部署者自己的真实数据保存在自己的 Cloudflare KV 中(初始灌入见 `scripts/seed-kv.mjs`)，
不会出现在公开仓库里。
